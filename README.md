# Medical Prescription App

A simple, responsive medical prescription and dosage calculator designed for doctors. It helps track patients, choose common medications, calculate suggested doses using weight-based formulas, and review safety alerts.

## Features
- Patient management
- Medicine catalog with common general medicines
- Weight-based dose calculation
- Safety alerts for high dose or age restrictions
- Prescription history
- Responsive UI for desktop and mobile

## Tech stack
- Node.js
- Express
- Vanilla JavaScript + HTML + CSS

## Run locally
```bash
npm install
npm start
```

Then open:
- http://localhost:3000

## Notes
This app is intended as a clinical decision support tool for educational and workflow demonstration use only. It does not replace clinical judgment or approved medical protocols.
